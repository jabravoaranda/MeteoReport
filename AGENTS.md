# MeteoReport: colaboración y ejecuciones

- Seguir el método acordado en `docs/METODO_INFORME.md` y conservar las decisiones
  científicas ya tomadas; distinguir funcionalidades disponibles de las pendientes.
- El usuario lanza los cálculos rutinarios desde VS Code para evitar usar la
  conversación como ejecutor de cada periodo. No iniciar lecturas largas de
  originales ni procesar toda la base de datos salvo que lo pida expresamente.
- Para cambios de presentación o redacción, usar resultados preparados y evitar
  releer originales. Se permiten pruebas sintéticas, verificaciones pequeñas y
  revisión de artefactos locales necesarias para el trabajo solicitado.
- Antes de una ejecución de datos, hacer explícitos el instrumento, periodo y fase
  (preparación o figuras/documento). No convertir una fase de figuras en una nueva
  extracción de red de forma implícita.
- No llamar a modelos desde los procesos locales para generar informes rutinarios.
- No interpretar ausencia de datos como ausencia de precipitación, ni disponibilidad
  de registros como prueba suficiente del estado operativo de un instrumento.
